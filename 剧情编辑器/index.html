这张图怎么看

中间的画布是一个场景：用户这一次来访，从上线到解决离开。从左往右，每一列是主线的一轮；每一列里竖着排的，是这一轮大肥鱼脑子里冒出来的候选，夜里会变成转盘上的扇区。

一张卡怎么看

  1. 属性：这张卡是哪种语言能力想出来的（颜色也跟着属性走）。玩家白天没学过的属性，夜里就想不到这张卡。
  2. 去向：选中后会怎样。→ 推进：用户满意，进入下一轮；↺ 重问：没解决，用户换个说法再问一次，这张卡划掉；⤓ 结局：对话就此结束（彩蛋等）。
  3. 方案词和预览：转盘上玩家看到的字。方案词高亮，后面灰字是预览。
  4. 结果和观感：策划给这张卡定的判定。结果 = 有没有解决用户的需求；观感 = 用户读完舒不舒服。
  5. 命中率：在顶部选的训练状态下，转盘第一次转就停在这张卡上的概率，也就是扇区有多大。它是按属性的权重分自动算的，不用手填。

徽章的意思

解决满足了用户这一轮真正想要的。推进 +1。
跑偏答非所问。扣耐心，用户重问。
糊弄大肥鱼在瞎编。用户没识破就算推进；识破了就骂人、扣耐心、重问。
坦白老实说不会。不推进；观感「舒服」时不扣耐心。
深层版 0 级·乱码版当前训练状态下，这张卡显示的是它的深层替换版 / 开放多样性没学时的胡言乱语版。
变灰的卡当前训练状态下不会上盘：要么属性没学过，要么被补进来的坦白卡挤掉了。

每一列的其他部分

  • 列头：用户这一轮发的话（气泡），右边是打字节奏；灰色小字是需求句，只给写剧本的人看，游戏里不出现。
  • 点赞变体 / 点踩变体：上一轮用户点了赞或踩之后，这一轮开口可以换一句更衔接的话。实线框 = 写了，虚线框 = 没写（用默认那句）。
  • 思考：大肥鱼思考链的前半段，播完就弹出转盘。
  • 备用坦白位：平时不上盘；只有这一轮能「解决」的卡全都没学过时，才自动补进来，给玩家一条认怂的路。
  • 特殊卡：彩蛋、Boss 的条件必出卡，平时不在盘上。

顶部的「预览：玩家训练到什么程度」

游戏里玩家白天给六个属性分别做预训练，每个属性可能是「没学 / 浅层 / 深层」，夜里的盘面就跟着变：没学过的属性，它的卡不会上盘；学到深层就换成深层版、更容易转到。选「第 1 天开局」能看到新玩家第一晚的盘面；要细查某种组合，点「自定义 ▾」逐个属性切换。

右边的编辑面板

点一张卡，右边显示的就是玩家选中它之后在游戏对话栏里看到的样子。鼠标移到哪句上，会出现蓝色虚线框和「✎ 能改什么」；点进去直接改，点外面就恢复成游戏里的样子。改过的地方和画布上对应的卡都会闪一下。灰色、带「沿用浅层」的句子是深层版 / 0 级版还没单独写的，点进去改了才算这一版自己的。
