# 大肥鱼工位立绘 · 接口说明（给画师）

> 2026-10-29 定稿。这份是给画大肥鱼工位动画的合伙人看的：照着交，放进文件夹，游戏和编辑器直接认，不用再转换。
> 规则的出处是 [美术与界面规范 §2、§8.2–8.4、§8.7](./大肥鱼游戏_美术与界面规范_v1.md)；两边说法不一样时以规范为准，并告诉我们改这份。

## 1 画的是什么

游戏右边是大肥鱼的工位（一间像素小房间），她**坐在桌子后面**，左下角。平时看着右边的显示器打字，有事的时候转过来看镜头。你画的就是她在这个位置的各种动作，逐帧动画。

## 2 画布（最重要的一条）

**所有动作、所有帧，都画在同一张 120×120 的画布上，人在画布里的位置保持一致。** 游戏不会缩放、不会裁边、不会帮你居中，画布原样贴到工位里——所以只要画布和位置一致，换动作时人就不会忽大忽小、往旁边跳。

| 项目 | 规格 |
|---|---|
| 画布 | **120 × 120 像素**，每个动作每一帧都一样 |
| 像素 | 1 个像素就是 1 个像素，**不要放大了再交**（游戏自己会放大：先 ×2 进房间，满屏时再 ×2，等于你的 1 像素显示成 4×4） |
| 桌面线 | **y = 110**（从上往下数，0 开始）。桌面线以下会被桌子挡住 |
| 她的位置 | 坐在桌后，**桌面线大约在她腰的位置**；腿不用画 |
| 大小 | 桌面以上露出 70–95 像素高（你的吃饭样稿约 67，可以再大一点） |
| 头顶 | 待机时头顶（含呆毛）离画布顶**至少 15 像素**，留给跳起来、举手、头上冒的符号 |
| 底色 | **透明** |
| 朝向 | 正面为主；**打字、思考要看向画面右边的显示器**（至少头和眼睛转过去） |
| 颜色 | 尽量贴近调色板（规范 §4.1，31 色）。不强制，检查页只提醒 |

**出图模板**：`游戏/素材/大肥鱼/模板.png`（120×120；以后出高精度版用 `模板_倍率1.png`，240×240）。上面有：红色的桌面线、桌下那一条灰（会被桌子挡住）、蓝色虚线（待机时头顶别高过它）、黄框（头像框），还有半透明的键盘、马克杯和显示器左边。把它垫在最底层画，画完把模板层隐藏再导出。编辑器检查页右上角也能直接下载。

- **头像框**：对话栏里她的小头像，是从 `idle` 第 1 帧按这个框裁出来的——**x 46–69、y 70–93（24×24）**，待机第 1 帧时脸（眼睛到嘴）要在框里。
- **可以点的区域**：白天玩家能点她，游戏按 `idle` 第 1 帧里有颜色的像素自动算，不用另交。

## 3 要画哪些动作

动作名（英文那列）就是接口，**名字要一字不差**。画多少交多少：没交的动作游戏自动用 `idle` 顶上。

| 动作名 | 动作 | 什么时候出现 | 播法 | 怎么画 |
|---|---|---|---|---|
| `idle` | 待机 | 平时 | 循环 | 呼吸、眨眼、尾巴慢摆都画在这段里：睁眼那帧停久一点（比如 3 秒），闭眼那帧很短（0.1 秒） |
| `type` | 打字 | 回答问题时 | 循环 | **看显示器**；双手交替敲键盘，呆毛随节奏抖 |
| `think` | 思考 | 转盘慢镜头 | 循环 | **看显示器或抬头看**；托腮，尾巴慢摆 |
| `talk` | 说话 | 剧情对白时 | 循环 | 要有嘴型（张合） |
| `read` | 看书 / 刷网页 | 白天预训练 | 循环 | — |
| `eat` | 吃白饭 | 白天吃白饭 | 循环 | 你的样稿就是这个；碗画在手里 |
| `sleep` | 睡觉 | 标题画面 | 循环 | — |
| `happy` | 开心 | 用户点赞、学会新东西 | 播一次 | 举手欢呼，尾巴快摆 |
| `panic` | 慌张 | 扣心、用户下线 | 播一次 | 冒汗、手忙脚乱 |
| `shock` | 震惊 | 糊弄被识破 | 播一次 | 全身一僵，呆毛竖直 |
| `stretch` | 伸懒腰 | 白天进夜里 | 播一次 | — |
| `pick` | 点选 | 白天点一项活动时 | 播一次 | 点一下头之类的小反应 |
| `daze` | 发呆 | 删库跑路之后 | 循环 | 对着黑屏愣住（排在最后，可以晚点交） |
| `coffee` | 喝咖啡 | 风控反杀 | 循环 | 杯子画在手里，悠闲（可以晚点交） |

- 「播一次」的动作播完会自动回到 `idle`，**最后一帧最好能自然接回待机**。
- 哪个循环、哪个播一次由游戏定，你只管画帧和每帧多长。
- **帧数建议**（不强制）：循环 4–8 帧，每帧 100–200 毫秒；播一次的 4–10 帧，**总长别超过 1.5 秒**（太长会拖住游戏流程）。
- **建议先交的顺序**：`idle` → `type` → `think` → `happy` → `panic` → `shock` → 其余。

## 4 什么画、什么不画

- **不画**：桌子、键盘、桌上的马克杯、白饭碗——这些房间自己会画。
- **要画**：拿在手里的东西（吃饭的碗、喝咖啡的杯子）画进帧里，游戏会同时把桌上那份藏起来。
- **要画**：嘴型、眨眼、汗滴、爱心这类长在她身上或贴着她的小效果，画在画布里就行。
- **不用画**：「卡顿」（复读机彩蛋）——游戏拿 `type` 的某一帧自己抽搐。

## 5 怎么交

### 5.1 用 Aseprite（推荐）

1. 一个 `.aseprite` 文件画全部动作，画布 120×120。
2. 每个动作在时间轴上打一个**标签（Tag）**，标签名就是第 3 节的动作名（如 `idle`、`type`）。
3. 每一帧的时长直接在 Aseprite 里设（帧属性里的 Duration）。
4. 导出：**文件 → 导出精灵图（Export Sprite Sheet）**
   - Layout：随便（By Rows / Packed 都行）
   - **不要勾 Trim**（裁掉空白会让位置变）
   - Output：勾 **JSON Data**（Hash 或 Array 都行），**Meta 里勾上 Tags**
   - 文件名：`大肥鱼.png` 和 `大肥鱼.json`
5. 把这两个文件，加上 `.aseprite` 原文件，一起放进 `游戏/素材/大肥鱼/`。

### 5.2 不用 Aseprite

一个动作一个文件夹，一帧一张透明 PNG，按顺序编号：

```
游戏/素材/大肥鱼/
  idle/01.png  02.png  03.png …
  type/01.png  02.png …
  时长.txt
```

`时长.txt` **必须有**：一行一个交了的动作（游戏只找这里列出的动作），后面写每帧多少毫秒（不写就按 130 毫秒）：

```
idle: 3000 100 3000 100
type: 120
```

只写一个数 = 这个动作每帧都是这么长；只写动作名 = 每帧 130 毫秒。

### 5.3 GIF

GIF 只当样稿看效果。背景是一整片纯色的，检查页会自动抠掉并提醒你；正式交的时候请用上面两种方式之一，透明底。

## 6 交之前自查（编辑器里的检查页会自动查这些）

打开编辑器 → 剧情 → 左边「🐟 工位动画」（或角色表里大肥鱼那张卡上的按钮），把文件或整个文件夹拖进去（也可以点「选文件…」「选文件夹…」）：

- [ ] 每一帧都是 120×120
- [ ] 动作名都对得上第 3 节（拼错的会列出来）
- [ ] 透明底
- [ ] 播一次的动作总长不超过 1.5 秒
- [ ] 待机第 1 帧时脸在头像框里
- [ ] 调色板外的颜色（只提醒）
- [ ] 叠在真实工位里逐个播一遍：桌面线、头像框可以开关着看

右边是真实的工位（可以切白天 / 夜里、开关参考线），点左边哪个动作就播哪个，下面一排是这个动作的每一帧和时长。看着没问题，点「装进游戏」：会把所有动作拼成一张 `大肥鱼.png + 大肥鱼.json` 写进 `游戏/素材/大肥鱼/`（原来的挪进 `_旧/`，不会丢）。画布不是 120×120 / 240×240 时装不进去。

- 分几次交也行：检查页里已经有的动作会留着，新拖进来的同名动作会替换掉旧的。可以先点「读游戏里现在的」，再拖新的进来，一起装。
- GIF 文件名就是动作名（如 `eat.gif`）时直接认；认不出时会问你是哪个动作。

## 7 以后：光影（现在不用交）

夜里的《空洞骑士》式光影游戏已经自己做了（屋里压暗、显示器发光、她朝屏幕那侧有一圈亮边），不用你画任何东西。下面是以后再升级用的：以后想让光打在她身上会反光、亮闪闪（显示器一闪，头发上的高光跟着闪；夜里显示器的蓝光在她右侧描一圈亮边）。到时候需要三张**可选**的图，和 `大肥鱼.png` 同样排布、逐帧对应：

| 文件 | 记的是什么 | 怎么来 |
|---|---|---|
| `大肥鱼_法线.png` | 每个像素朝哪个方向 | 用 Laigter 这类工具从原图自动生成，再手修几处 |
| `大肥鱼_光泽.png` | 每个像素多光滑（灰度，越白越亮闪闪：头发、眼睛、碗亮，衣服不反光） | 手涂灰度 |
| `大肥鱼_发光.png` | 自己会发光的像素（爱心、眼睛里的高光点） | 可以不画 |

在 Aseprite 里可以做成同一个文件的另外几个图层，分别导出成同排布的图。**现在一张都不用交**，等光影那一步开始时再说。
