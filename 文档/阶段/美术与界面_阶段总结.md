## 2 已定的方案（要点，细节见规范）

**风格**
- 全像素艺术，960×540 美术像素按整数倍放大（1080p 下 2 倍）；字体统一用 Fusion Pixel 12px（OFL 1.1，已核实）。
- 「像素渲染，现代排版」：4 的倍数间距、平面色块分层、像素阶梯圆角、三级文字。
- 界面中性色是纯黑灰阶；蓝色留给场景和强调色；**红色只用于危险信息，紫色只用于 ×3 倍速和彩蛋**。卡牌颜色跟着属性走（知识覆盖钴蓝、口语活力暖金……）。
- 「写实」只约束内容，不约束画面；动画要夸张、有爽感；故障效果只在出事时出现。

**窗口：伪装成 agent 工具「大肥鱼 HARNESS」**
- 最左：可折叠图标栏 / 侧栏（今晚的会话、存档 SAVE / 读档 LOAD、设置）。
- 中间：对话栏，样式照真实深色 agent 应用，**用户靠左带气泡、大肥鱼靠右不带气泡**；输入框归用户（用户在里面打字，节奏透出情绪）；底部状态栏有轮次、推进、耐心；「对话 / 轨迹」两个标签。
- 右侧：仿浏览器预览窗，两个标签页——「大肥鱼的工位」和「自我认知」（模型评测报告：雷达图、属性阶段、统计）。
- 独立的 SL 界面（日系 ACT / galgame 式）：SAVE 钴蓝 / LOAD 玫粉，Q 快速、A 自动、1–5 页，3×2 卡片带工位缩略图，覆盖 / 读取确认，`SAVED` 印章，`LOADING` 过场。
- 每个按钮都必须有反馈；没做的功能也给按下效果 + 提示（带梗）。

**工位（右侧场景）**
- 大肥鱼在左下，紧挨对话栏，侧身看向右边的显示器；反应动作时才看镜头。
- 显示器屏幕朝外：思考时是「推理控制台」，选定方案词后切到对应应用（百科 / 聊天 / 原稿纸 / IDE / 公文 / 花屏 / 弹幕 / 记事本 / 终端 / 复读）。
- **分词机**：显示器旁的小机器，token 从它顶部吐出，3 位大号数码管显示本轮 token 数。
- 房间家具常驻，预训练往里填东西、深层再升级（书架、布告板、衣钩、笔记本、书立）——房间就是「自我认知」的可视化。
- 墙上：大窗户城市夜景、像素时钟、日历、藏字标语「不怕困难 · 挑战困难 · 战胜困难」（夜里用暗纸色）。

**关键节点**
- token 自由飞行（按词分词、先占位后飞、各走各的弧线），没有固定滑轨。
- 前文最后一个 token 起飞即进入子弹时间；思考气泡只在关键节点从她头顶弹出（候选列表 + 转盘，指针在顶部）。
- 转盘：蓄力 → 甩出 → tick 火星 → 犹豫停下 → 命中定格冲击波；抹除 / 剔除时额度格从 HUD 飞到扇区；确认时选中的词直接砸进对话栏的空位。
- 心和额度在工位右下角；Tibo 重置是一次性事件，弹假 X 手机（头像像素化 + 眼睛打黑条），点 × 才关闭。

**音频**：全部程序化生成。音效带短回声；夜间 chiptune 循环（Am–F–C–G），子弹时间里变慢变闷并叠心跳。音乐风格参考《主播女孩重度依赖》。

## 4 原型现状

- **能做的**：一整轮夜间流程（用户上线 → 打字提问 → 思考 → 子弹时间转盘 → 抹除 / 剔除重转 / 确认 → 回复 → 用户 👍 / 👎 → 扣耐心 / 推进）、糊弄被识破、彩蛋扇区、Tibo 重置、倍速滑杆（可拖）、侧栏、SL 存读档、自我认知标签、轨迹日志、10 种屏幕应用、房间物件随阶段变化、音效和背景音乐。
- **原型面板**（左上白色浮窗，不属于设计）：切房间阶段、调手感参数、模拟训练后的概率、插入彩蛋、强制识破、额度设 3、预览各屏幕应用。
- **都是占位的**：大肥鱼精灵（参考图抠图 + 水平翻转，只有上下晃动）、小学生和 Tibo 的点阵头像、只有一轮剧本（好奇的小学生问天空为什么是蓝的）。
  - 更新（v3.5）：原型已改为读 `剧本/` 下的剧本库，能跑整场（主线 + 重问 + 分叉结局），终端样式的候选和「运行了命令」卡也做了，详见 [剧情编辑器_设计.md](../策划/剧情编辑器_设计.md)。
- **没在原型里做的**：白天训练界面、代码求助轮次的终端样式气泡、彩蛋的完整演出（目前只弹通知）、Boss 战、结算弹窗、Day 0 教学、回档 / 整局结束界面、成就提示。
- **测试注意**：在后台的预览窗会降帧，动画手感要在前台全屏（1920×1080）看。
